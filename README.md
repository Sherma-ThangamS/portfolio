## 🚀 Getting Started

### Prerequisites

- **Node.js**: v20.x, v22.x, or v26.x
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/Sherma-ThangamS/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install
```

### Development & Production

```bash
# Run local Vite development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
